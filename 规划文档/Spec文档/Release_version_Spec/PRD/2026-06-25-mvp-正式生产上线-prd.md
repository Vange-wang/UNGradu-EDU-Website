# 家教对接平台 MVP 正式生产上线 PRD

日期：2026-06-25
状态：PRD 草案，待业务方确认后转正式 Spec
阶段：MVP 完结后正式生产上线准备
上线口径：小范围生产试运行
产品角色：产品经理

## 1. 背景

家教对接平台 MVP 已完成 M1、M2、M3、M4、M5 阶段验收。M5 托管环境最终验收确认，CloudBase Run 测试服务已在真实公网地址下完成 `npm run m5:hosted:verify` 复验，HTTP flow 与 50 虚拟用户 load 均通过。

MVP 发布前收口阶段已围绕产品说明、生产环境变量清单、测试账号管理、上线回滚预案、正式生产禁用测试登录确认、代码底层架构和规范性进行了集中治理。当前项目可以从“测试托管环境验收通过”推进到“正式生产环境小范围试运行”。

本阶段不扩大 MVP 业务范围，不新增支付、评价、审核后台、实名认证、举报封禁、自动推荐等 vNext 功能。

## 2. 阶段目标

本阶段目标是完成 MVP 的正式生产小范围试运行上线。

核心目标：

- 建立独立生产环境。
- 配置正式生产环境变量。
- 禁用所有测试登录能力。
- 使用生产专用强随机密钥。
- 完成生产部署、生产冒烟、回滚演练和上线验收。
- 明确测试账号、试运行账号、真实用户账号边界。
- 形成上线说明、生产配置清单、回滚预案、验收报告。
- 将公开列表约 1000 条近期公开记录分页上限纳入后续技术债或 vNext 性能优化清单。
- 确认 MVP 阶段正式完结，项目进入生产试运行与 vNext 规划并行阶段。

## 3. 上线口径

本阶段采用“小范围生产试运行”，而不是直接公开上线。

定义：

- 使用真实生产环境或正式试运行生产环境。
- 使用生产配置与生产密钥。
- 禁用测试登录。
- 面向内部人员和少量受邀种子用户开放。
- 不做大规模公开推广。
- 允许收集真实业务反馈，但必须保留回滚和人工干预能力。

不建议直接公开上线的原因：

- 正式登录方案、运营处理机制、监控告警、用户协议和隐私说明仍需进一步完善。
- vNext 的真实性、认证、审核和风控能力尚未进入当前阶段。
- 当前更适合先验证真实生产环境下的 MVP 闭环和运营响应能力。

## 4. 用户与开放范围

| 用户类型 | 说明 | 本阶段开放策略 |
| --- | --- | --- |
| 内部测试人员 | 产品、开发、运营或业务方指定人员 | 开放 |
| 种子家长/学生 | 少量受邀真实需求方 | 可控开放 |
| 种子大学生老师 | 少量受邀可授课大学生 | 可控开放 |
| 普通公网用户 | 未经邀请的自然访问用户 | 暂不主动推广 |

本阶段允许真实用户小范围使用，但不应做大规模投放、公开宣传或增长活动。

## 5. 正式生产上线定义

本阶段的“正式生产上线”必须同时满足：

- 服务部署在正式生产 CloudBase Run 或等价生产环境。
- 使用生产环境变量。
- 使用生产独立数据环境，或明确隔离的正式试运行数据环境。
- `APP_ENV=production`。
- 不启用 `M5_ENABLE_HOSTED_TEST_LOGIN=true`。
- 不启用 `NEXT_PUBLIC_ALLOW_TEST_LOGIN=true`。
- `/api/auth/test-login` 在生产环境不可用。
- `x-ungradu-test-user-phone` 备用测试身份路径在生产环境不可用。
- 生产 `AUTH_SESSION_SECRET` 独立强随机，不复用测试密钥。
- 完成生产 URL 下核心流程冒烟。
- 有回滚预案和回滚验收路径。
- 有上线验收报告归档。

## 6. 本阶段包含范围

### 6.1 生产环境准备

必须完成：

- 创建或确认生产 CloudBase 环境。
- 创建或确认生产 CloudBase Run 服务。
- 配置生产数据库集合。
- 配置生产环境变量。
- 配置生产域名或正式公网访问地址。
- 确认生产部署镜像或提交版本。
- 确认生产环境日志查看入口。
- 确认生产环境权限管理人员。

### 6.2 生产环境变量清单

生产必须配置：

```text
APP_ENV=production
AUTH_SESSION_SECRET=<生产专用强随机密钥>
CLOUDBASE_ENV_ID=<生产 CloudBase 环境 ID>
TENCENTCLOUD_SECRETID=<生产环境腾讯云 SecretId>
TENCENTCLOUD_SECRETKEY=<生产环境腾讯云 SecretKey>
```

生产必须关闭或不设置：

```text
M5_ENABLE_HOSTED_TEST_LOGIN
NEXT_PUBLIC_ALLOW_TEST_LOGIN
```

禁止事项：

- 禁止将真实密钥写入 Git。
- 禁止将真实密钥写入规划文档正文。
- 禁止在聊天记录、报告正文中记录完整 SecretId、SecretKey、AUTH_SESSION_SECRET。
- 禁止复用测试环境 `AUTH_SESSION_SECRET`。
- 禁止使用 M5 测试登录作为真实用户登录方式。

### 6.3 正式生产禁用测试登录确认

必须验证：

- 生产环境 `APP_ENV=production` 生效。
- `/api/auth/test-login` 返回拒绝结果。
- 即使误配 `M5_ENABLE_HOSTED_TEST_LOGIN=true`，生产仍拒绝测试登录。
- 即使误配 `NEXT_PUBLIC_ALLOW_TEST_LOGIN=true`，生产仍拒绝测试登录。
- 通过 `x-ungradu-test-user-phone` 请求头伪造测试用户时，生产仍拒绝。
- 前端页面不展示“测试验证码 000000”“测试账号登录”等测试入口。
- 登录态 Cookie 使用生产密钥签发。
- 生产密钥轮换影响已说明：轮换后现有在线用户会被强制登出。

### 6.4 正式登录方案确认

本阶段需要确认真实用户登录方式。

最低要求：

- 生产环境不能依赖 M5 测试登录。
- 若正式短信登录尚未接入，必须明确试运行用户如何登录。
- 如果使用人工发放验证码、白名单手机号或临时运营登录方案，必须写清楚风险和有效期。
- 若当前真实手机号短信登录不可用，则不得进行完全公开上线，只能做受控试运行或生产预发布。

建议决策：

- 小范围试运行阶段可以采用“受邀手机号白名单 + 正式验证码或运营确认机制”。
- 不允许使用 `000000` 测试验证码作为生产登录手段。

### 6.5 测试账号与试运行账号管理

必须区分：

| 账号类型 | 用途 | 可否在生产使用 |
| --- | --- | --- |
| M5 测试账号 | 自动化验收、测试托管环境验证 | 不可 |
| 本地开发账号 | 本地开发调试 | 不可 |
| 试运行账号 | 受邀真实用户或内部试运行人员 | 可 |
| 真实用户账号 | 小范围真实业务使用 | 可控开放 |

必须说明：

- 测试账号不得迁入生产。
- 测试数据不得混入生产。
- 试运行账号应有名单或识别方式。
- 生产问题排查不得直接读取或公开用户敏感联系方式。
- 清理测试数据时不得误删真实用户数据。

### 6.6 生产冒烟验收

生产 URL 下必须完成以下路径：

1. 首页访问。
2. 登录入口检查。
3. 生产测试登录禁用检查。
4. 家长身份入口进入。
5. 大学生身份入口进入。
6. 家长发布需求。
7. 大学生发布家教信息。
8. 家长浏览家教信息广场并筛选。
9. 大学生浏览需求广场并筛选。
10. 进入详情页。
11. 发起站内聊天。
12. 双方发送文字消息。
13. 发起联系方式交换请求。
14. 接收方同意。
15. 二次确认后双方查看授权联系方式。
16. 登出。
17. 重新登录后数据仍可读取。
18. 未授权用户不能读取他人联系方式。
19. 非参与者不能读取会话。
20. 反馈入口可访问并可提交或打开真实反馈渠道。

### 6.7 生产性能与稳定性验收

最低要求：

- 生产环境完成一次小规模 HTTP flow。
- 生产环境完成一次基础并发验证。
- 可参考 M5 的 50 虚拟用户 load，但生产试运行阶段应根据云资源谨慎执行。
- 若不在生产执行压测，必须说明原因，并以测试托管压测结果作为参考，不得混称为生产压测。

建议指标：

| 指标 | 目标 |
| --- | --- |
| HTTP flow 成功率 | 100% |
| 基础 load 成功率 | 99% 以上 |
| 核心 API 错误率 | 1% 以下 |
| 首页可访问 | 必须 |
| 核心流程可完成 | 必须 |
| 联系方式未授权读取 | 必须拒绝 |

### 6.8 生产回滚预案

必须形成可执行回滚文档。

至少包含：

- 当前上线提交。
- 当前上线镜像。
- 上一稳定提交。
- 上一稳定镜像。
- CloudBase Run 回滚方式。
- 环境变量回滚方式。
- 数据库变更是否可逆。
- 回滚触发条件。
- 回滚执行人。
- 回滚后验收步骤。
- 回滚通知口径。

回滚触发条件建议：

- 生产登录不可用。
- 核心发布流程不可用。
- 聊天不可用。
- 联系方式保护失效。
- 出现测试登录可在生产使用。
- 数据权限出现越权。
- 生产环境大面积 5xx。
- 无法在 30 分钟内定位的核心路径故障。

### 6.9 上线公告与产品说明

面向用户说明：

- 平台是家教自助撮合 MVP。
- 当前免费。
- 平台不做支付担保。
- 平台不做线下交易保障。
- 平台不做老师资质强审核。
- 用户需自行判断授课风险。
- 联系方式需双方同意后交换。
- 遇到虚假信息、骚扰、联系方式滥用可通过反馈入口联系平台。
- 当前处于小范围试运行，功能可能持续调整。

面向内部说明：

- 当前上线范围。
- 当前不包含范围。
- 已知技术债。
- 试运行观察指标。
- 问题反馈路径。
- 应急联系人和响应方式。

### 6.10 监控与问题处理

本阶段不要求建设完整监控平台，但必须具备最低运维可见性。

最低要求：

- 能查看 CloudBase Run 服务状态。
- 能查看服务运行日志。
- 能查看部署版本。
- 能查看环境变量配置但不泄露真实值。
- 能定位核心 API 5xx。
- 能人工确认反馈入口收到的问题。
- 能记录生产问题处理过程。

建议新增文档：

- `生产问题记录.md`
- `生产上线检查清单.md`
- `生产试运行日报或观察记录.md`

## 8. 已知技术债处理口径

### 8.1 公开列表约 1000 条近期公开记录分页上限

当前状态：

- M5 已修复新发布公开记录不可见问题。
- 当前公开列表读取约 1000 条近期公开记录。
- 当有效公开记录超过约 1000 条时，较旧记录可能退出公开列表窗口。

本阶段处理：

- 不阻塞生产小范围试运行。
- 必须写入技术债清单。
- 必须在 vNext 性能优化中规划游标分页、数据库索引或服务端分页 API。

### 8.2 证明图片能力边界

当前状态：

- MVP 不应暗示已具备正式证明图片审核能力。

本阶段处理：

- 产品说明中明确边界。
- 页面文案不得夸大。
- 真实图片上传、查看、审核进入 vNext 真实性迭代。

### 8.3 正式短信登录能力

当前风险：

- 如果未接入正式短信服务，则生产公开登录不可直接开放。

本阶段处理：

- 小范围试运行前必须确认真实登录方案。
- 若暂不接短信，只能做受控试运行。
- 公开上线前必须补正式登录方案 Spec。

### 8.4 运营审核与风控

当前状态：

- MVP 仅提供基础规则和联系方式保护。
- 不提供完整审核、举报封禁、实名认证。

本阶段处理：

- 试运行期间采用人工观察和反馈入口处理。
- vNext 再设计真实性、认证、审核后台、举报封禁。

- 生产环境仍可使用 `/api/auth/test-login`。
- 生产页面仍展示测试登录入口。
- 生产 `AUTH_SESSION_SECRET` 复用测试密钥。
- 生产环境真实密钥被写入 Git 或文档正文。
- 核心流程无法在生产 URL 跑通。
- 联系方式未授权读取保护失败。
- 非参与者可读取会话或联系方式。
- 没有回滚预案。
- 没有生产环境变量清单。
- 没有测试账号与试运行账号边界说明。
- 没有上线验收报告。
- 若正式短信登录未接入，却试图完全公开上线。

## 10. 验收标准

生产试运行上线完成需满足：

- 生产环境部署完成。
- 生产 URL 可访问。
- 环境变量清单完成并逐项确认。
