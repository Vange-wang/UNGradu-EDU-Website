## 4. D6：邮箱验证码前人机验证（技术默认冻结，实际 widget/secret 外部）

### 4.1 供应商与信任边界

- 默认候选：**Cloudflare Turnstile Free**；优先请求 `widget region=china`。若当前账户
  或免费计划不支持该 region，保持阻塞，不能静默改为 `world` 或换未确认 provider。
- 生产 hostname allowlist 仅为：`ungraduedu.eu.cc`、`www.ungraduedu.eu.cc`。旧域名只有
  在仍承载生产流量且业务方另行明确保留时才可加入；不默认加入。
- action 精确为 `email_send_code`。浏览器 challenge 只产生 token；服务端必须调用
  Siteverify，并精确检查 `success`、hostname、action、时效和单次消费后，才允许发送
  邮箱验证码。客户端勾选、前端状态或旧路径均不授权发送。
- provider token TTL `300 秒`；应用层 freshness `≤120 秒`。服务端普通超时目标 `2 秒`，
  硬上限 `5 秒`；验证失败、超时、服务不可达、字段不符、secret 缺失均 fail-closed，
  失败发送数必须为 `0`。

### 4.2 限流、隐私、环境与轮换

| 控制 | 冻结默认 |
| --- | --- |
| 账号限流 | `3 次/15 分钟`、`10 次/24 小时` |
| IP 限流 | `10 次/15 分钟` |
| provider IP 字段 | 默认不传 `remoteip` |
| 本地 IP | 仅使用 HMAC 摘要做限流，`24 小时`内删除；不写明文 IP 到普通日志 |
| widget/secret | 测试与生产完全分离；secret `90 天`轮换；真实 secret 不入仓库/普通日志 |
| 语言与无障碍 | `auto/zh-cn`，保留可操作的无障碍替代路径且仍须服务端验证 |
| 成本 | 免费成本上限 `0 CNY`；转付费必须重新取得业务确认 |
