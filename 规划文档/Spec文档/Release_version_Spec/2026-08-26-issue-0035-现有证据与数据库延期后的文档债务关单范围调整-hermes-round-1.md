## Serious Findings

### S1 — N-011 引用的「旧 V7 R1 report」SHA 未在 §1.1 事实来源登记，证据链不可回读

- **严重度**：SERIOUS
- **位置**：§3 矩阵 N-011 行（第 66 行）
- **证据**：N-011 的「精确证据/引用与边界」写为：
  > 原 V7 Spec §5 N-011 与旧 V7 R1 report SHA=`578B2ACBD243149F02C4A99FDE464AD742538E2311A53385A6065B9EDAD4F580`

  但 §1.1「事实来源」表（第 12–21 行）登记的 8 个来源中**没有任何一条**包含该 SHA，也没有该「旧 V7 R1 report」的文件路径。该 SHA 与 ISSUE-0045 的 SHA（`56DF9D7301...`，第 16 行）前导字节不同，可确认是另一个未登记文档，而非笔误。
- **影响**：
  1. 违反 §6（第 98 行）自设规则「任何来源 hash/路径不一致 … 均为 `REVIEW_BLOCKED`，不得关单」——有 hash 无路径即属来源不可核验。
  2. 违反 §7（第 114 行）可测试标准「所有报告和最终 hash 可回读」——该 report hash 无路径、无章节可读，无法回读。
  3. N-011 被标记为 `CURRENT_CLOSURE_SUFFICIENT`，其证据含一个不可核验来源，等于把不可核验项写成了「文档采纳完成」。
- **纠正**：二选一：
  - (a) 在 §1.1 事实来源表补登记「旧 V7 R1 report」的完整路径 + SHA，并同步 §7 来源核验清单；
  - (b) 若该 report 非 N-011 必要证据，删除 SHA 引用，仅保留「原 V7 Spec §5 N-011」作为证据来源。
- **未来关单触发**：整改后须保证 §6 hash/路径规则与 §7「所有 hash 可回读」同时满足。
