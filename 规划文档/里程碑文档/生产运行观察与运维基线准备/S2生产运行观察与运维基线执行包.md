# S2 生产运行观察与运维基线执行包

日期：2026-06-30

任务 ID：`RELEASE-S2-OPS-2026-06-30-001`

阶段：发布阶段 S2

阶段名称：生产运行观察与运维基线

当前前置状态：S1 已完成，Open Issue 为空。

## 1. 背景

S1 已完成 MVP 生产主链路收口，项目总控制人已确认聊天、交换联系方式、保存密码、密码登录、登录状态 UI 同步等核心链路正常。

S2 不新增业务功能，也不承诺客服与人工介入能力。S2 的目标是把当前小范围生产试运行从“功能能用”推进到“运行可观察、问题可分级、部署可核对、异常可回滚”。

## 2. S2 目标

- 建立生产运行观察记录格式。
- 建立生产问题分级与响应规则。
- 建立部署回滚与环境配置核对清单。
- 建立数据库集合与权限配置检查表。
- 增加一条代码侧无密钥运维基线检查命令，用于确认生产运行口径和配置要求没有漂移。

- 该脚本至少检查：

  - 当前发布基线 / 回滚基线是否填写。
  - S2 运行观察文档是否存在。

## 4. S2 不做范围

- 不做客服与人工介入。
- 不做智能 Agent 客服。
- 不做支付、合同、排课、课时记录、评价、自动推荐。
- 不新增后台管理系统。
- 不读取、导出或修改生产用户数据。
- 不把真实密钥、真实邮箱、真实验证码或生产数据库内容写入仓库。

## 5. 问题分级口径

| 等级 | 定义 | 响应口径 |
| --- | --- | --- |
| P0 | 登录、发布、聊天、联系方式交换任一主链路整体不可用，或出现隐私 / 越权 / 密钥泄露风险 | 立即停止扩大试运行，优先修复，必要时回滚 |
| P1 | 主链路局部失败、生产配置错误、验证码 / 密码登录不稳定、数据写入失败 | 当日进入修复或明确外部依赖，修复后复验 |
| P2 | 明显体验问题、提示不清、返回入口缺失、非核心页面展示问题 | 纳入 S2 观察清单或下一轮体验修复 |
| P3 | 文档、样式、运营说明、非阻塞优化 | 进入后续迭代池 |
