# vNext 性能优化与技术债清单

日期：2026-06-24
来源：MVP 发布前收口与架构治理 Spec

## 1. 公开列表分页上限

当前 M5 修复已将公开列表查询改为按 `status=published`、`createdAt desc`、`skip` / `limit` 分页读取近期公开记录。当前策略最多读取约 1000 条近期公开记录。

后续需要明确产品语义：

- 若只展示近期活跃发布，应在产品文案和排序规则中明确。
- 若必须支持完整历史回溯，应升级为数据库索引、游标分页或服务端分页 API。

## 2. 老师资料价格区间模型与 UI 对齐

当前模型支持 `feeRanges` 数组，UI 只编辑第一组价格区间。

后续方向：

- MVP 若只保留单组价格区间，应收敛模型与文案。
- vNext 若支持多组价格区间，应补充新增、删除、展示和筛选规则。

## 3. 旧 localStorage 代码治理

M5 主路径已迁移到服务端 API，旧本地存储逻辑仍用于历史阶段、测试或兼容。

后续方向：

- 标记 legacy。
- 删除不再使用路径。
- 保留必要测试工具时明确边界。

## 4. 通用工具抽取

后续可逐步抽取：

- 重复校验规则。
- ID 生成规则。
- 分页工具。
- 错误处理工具。
- API client 响应解析工具。

其中 API client 响应解析已在本阶段先行抽取为 `features/api/api-client.ts`。
