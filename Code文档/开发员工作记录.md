# 开发员工作记录

用途：持续记录程序开发员在本项目中的代码更新、代码文档更新、目录结构调整、实现功能、验证结果、遗留风险和后续优化预测。

本文件只记录开发侧工作，不替代产品 Spec、里程碑或产品经理工作记录。任何业务范围、验收标准和优先级仍以 `规划文档/Spec文档` 和 `规划文档/里程碑文档` 为准。

## 记录规则

- 每次新增、修改或删除业务代码后，必须追加记录。
- 每次调整代码目录、开发命令、测试命令、部署方式或环境变量说明后，必须追加记录。
- 每次根据 Spec 完成一个功能点后，必须写明对应的 Spec 范围和验收方式。
- 如果某项验证无法运行，必须写明原因、影响和后续补救方式。
- 不修改产品经理工作记录；如开发发现会影响产品决策的问题，应先向业务方或产品经理确认。
