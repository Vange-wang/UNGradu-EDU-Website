# 正式生产禁用测试登录确认

日期：2026-06-24
阶段：MVP 发布前准备

## 1. 发布前确认项

| 确认项 | 状态 | 说明 |
| --- | --- | --- |
| 生产环境 `APP_ENV=production` 已配置 | 生产发布前阻塞项 | 尚未提供正式生产环境配置证据 |
| 生产环境未配置 `M5_ENABLE_HOSTED_TEST_LOGIN=true` | 生产发布前阻塞项 | 若误配为 `true`，服务端也必须拒绝 |
| 生产环境未配置 `NEXT_PUBLIC_ALLOW_TEST_LOGIN=true` | 生产发布前阻塞项 | 若误配为 `true`，服务端也必须拒绝 |
| 生产 `AUTH_SESSION_SECRET` 已配置且不是测试密钥 | 生产发布前阻塞项 | 不记录真实值 |
| `/api/auth/test-login` 在生产环境返回拒绝结果 | 生产发布前阻塞项 | 需生产 URL 下验证 |
| `x-ungradu-test-user-phone` 备用测试身份在生产环境返回拒绝结果 | 生产发布前阻塞项 | 需生产 URL 下验证 |
| 前端页面不展示测试验证码给真实用户 | 待发布前验证 | 生产登录方案确认前不得开放真实公网用户 |
| `AUTH_SESSION_SECRET` 轮换影响已评估 | 待发布前确认 | 轮换会导致现有会话失效 |

## 2. 当前代码侧证据

- `APP_ENV=production` 是测试登录禁用主闸。
- 单元测试已覆盖生产环境误配测试开关仍拒绝临时测试登录。
- M5 测试托管环境使用 `APP_ENV=test` 与 `M5_ENABLE_HOSTED_TEST_LOGIN=true`，只用于隔离验收。

## 3. 生产发布前必须补齐

正式生产 URL 可访问后，必须记录以下验证证据：

```powershell
# 预期：返回 401 或等价拒绝结果，不写入测试登录 Cookie
Invoke-WebRequest -Method Post -Uri '<生产地址>/api/auth/test-login' -ContentType 'application/json' -Body '{"phone":"13800138000","code":"000000"}'
```

同时需要验证业务 API 在带 `x-ungradu-test-user-phone` 请求头时拒绝测试身份。若无法提供生产环境证据，本清单保持“生产发布前阻塞项”。
