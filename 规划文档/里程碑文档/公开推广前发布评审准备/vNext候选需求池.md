# vNext 候选需求池

日期：2026-06-30

阶段：发布阶段 S4

## 1. 高优先级候选

| 需求 | 原因 |
| --- | --- |
| 智能 Agent 客服专项 | 补齐客服与人工介入缺口前的辅助承接能力 |
| 举报 / 投诉最小闭环 | 公开推广前必须有风险反馈处理链路 |
| 老师资料审核状态 | 避免用户误以为平台已认证 |
| 风险提示组件 | 统一表单、详情、聊天、联系方式交换中的风险提示 |
| 生产运行观察记录持续化 | 支撑小范围试运行 |

## 2. 中优先级候选

| 需求 | 原因 |
| --- | --- |
| 运营后台最小版 | 管理反馈、需求、老师资料和风险记录 |
| 简单评价 / 反馈标签 | 帮助识别优质或异常用户 |
| 内容敏感信息提示 | 降低公开内容泄露联系方式风险 |
| 数据看板 | 观察发布、聊天、联系方式交换转化 |

## 3. 暂缓候选

| 需求 | 暂缓原因 |
| --- | --- |
| 在线支付 | 需要合同、退款、风控和资质审核配套 |
| 平台担保交易 | 高风险，不适合当前 MVP |
| 实名认证 | 需要供应商、合规和隐私评审 |
| 自动推荐算法 | 当前样本不足，先人工观察 |
| 复杂排课 | 不影响当前撮合 MVP |

## 4. 下一步建议

S4 后建议优先进入：

1. 智能 Agent 客服专项 Spec。
2. 举报 / 投诉最小闭环 Spec。
3. 公开推广前风险提示组件执行包。
4. 小范围试运行观察记录持续更新。
