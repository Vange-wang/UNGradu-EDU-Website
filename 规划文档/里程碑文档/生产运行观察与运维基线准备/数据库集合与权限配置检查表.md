# 数据库集合与权限配置检查表

日期：2026-06-30

适用阶段：发布阶段 S2

## 1. 必备集合

| 集合 | 用途 | S2 检查口径 |
| --- | --- | --- |
| `contact_profiles` | 当前用户联系方式存档 | 只允许用户读取 / 保存自己的联系方式 |
| `parent_needs` | 家长 / 学生找老师需求 | 公开读取使用白名单；私有读写校验 owner |
| `tutor_profiles` | 大学生家教信息 | 公开读取使用白名单；私有读写校验 owner |
| `conversations` | 会话列表和会话元数据 | 只允许参与者读取 / 创建相关会话 |
| `messages` | 聊天消息 | 只允许会话参与者读取 / 发送 |
| `contact_exchange_requests` | 联系方式交换请求 | 只允许会话参与者按角色操作 |
| `email_login_codes` | 邮箱验证码哈希和状态 | 验证码不以明文保存；成功登录 / 重置后才消费 |
| `email_login_users` | 邮箱登录用户和密码哈希 | 密码不明文保存；不向前端返回 hash / salt |

## 2. 权限边界

- 生产环境不得接受 `x-ungradu-test-user-phone` 临时身份。
- 生产环境不得启用测试登录入口。
- API 不得信任客户端传入的 ownerUserId。
- 公开列表 / 详情不得返回联系方式、ownerUserId、密码哈希、验证码信息。
- 联系方式交换必须经过会话参与、同意、二次确认和未过期检查。

## 3. 检查方式

- 无密钥本地口径检查：`npm run production:ops:baseline`。
- 真实 CloudBase 可读性检查应由项目总控制人在安全环境执行，不在仓库中记录真实密钥。
- 如发现集合缺失或权限异常，应登记 S2 新 Issue，并从 `ISSUE-0016` 起编号。
