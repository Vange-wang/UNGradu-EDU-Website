# 公开推广风险清单

日期：2026-06-30

阶段：发布阶段 S4

## 1. 当前结论

当前不建议大规模公开推广。

建议保持小范围生产试运行，继续收集真实用户反馈，并优先补齐客服、举报处理、审核和运营承接能力。

## 2. 阻止公开推广的核心风险

| 风险 | 当前状态 | 影响 |
| --- | --- | --- |
| 客服与人工介入缺失 | 未建设 | 用户遇到骚扰、纠纷、虚假信息时无法获得明确承接 |
| 智能 Agent 客服缺失 | 未建设 | 不能用自动客服替代人工承接 |
| 正式举报处理闭环缺失 | 仅有反馈入口临时承接 | 不适合大规模用户投诉处理 |
| 老师资料审核能力缺失 | 仅有规则说明 | 不能承诺老师身份、学校、资质真实性 |
| 实名认证缺失 | 未建设 | 无法支持高信任公开推广 |
| 支付 / 合同 / 退款缺失 | 未建设 | 不适合宣传为交易型平台 |
| 运营承接能力不明 | 未建立团队 / 值守机制 | 大量用户进入后风险不可控 |

## 3. 可接受的小范围试运行条件

- 明确告知用户当前是 MVP / 小范围试运行。
- 不宣传平台认证、担保交易、即时客服、人工审核。
- 继续使用反馈入口收集风险和功能问题。
- 继续保持 Open Issue 为空或仅保留非阻塞观察项。
- 生产运行观察记录持续更新。

## 4. 触发暂停推广的条件

- 出现 P0 安全 / 隐私问题。
- 测试登录在生产环境可用。
- 公开页面泄露联系方式或内部字段。
- 验证码 / 密码登录不稳定且影响主链路。
- 聊天或联系方式交换出现越权。
- 用户反馈集中出现骚扰、虚假信息、线下交易纠纷且无法承接。
