# UI美术文档

用途：集中存放本项目 UI 设计师负责的视觉设计、界面改版、草图模板、阶段定稿、设计验收和交接材料。

## 目录职责

| 目录 | 职责 |
| --- | --- |
| `设计输入与素材/` | 存放用户提供的参考图、截图、海报、页面素材、竞品参考和设计输入说明。 |
| `草图模板/` | 存放低保真草图、线框模板、页面布局草案和可复用设计模板。 |
| `大方向改版/` | 存放整站视觉方向、核心页面重设计、风格探索和成套改版方案。 |
| `小细节调整/` | 存放局部 UI 优化、按钮、表单、文案层级、状态样式、间距和响应式细节调整。 |
| `阶段设计定稿/` | 存放已被确认的阶段设计稿、视觉规范、页面清单和设计冻结记录。 |
| `设计验收与交接/` | 存放给产品经理、代码开发员、ISSUE 管理员或总负责人的设计验收与实现交接说明。 |
| `历史归档/` | 存放已废弃、被替换或仅供追溯的旧设计方向和旧交接材料。 |

## 关键文件

- `钦定UI设计师.md`：定义 UI 设计师 Agent 的身份、职责边界、工作方式和接续提示。
- `UI设计师工作记录.md`：持续记录 UI 设计师每次设计决策、目录调整、方案输出和交接动作。
- `UI设计师Agent身份注册信息.md`：登记 UI 设计师 Agent 的身份注册信息。当前 v2.2.0 会话 ID 已迁移绑定为 `019f70ed-f088-77e1-8bdc-bede547e5231`；v2.1.0 ID 仅作历史归档。

## 工作原则

- UI 设计师负责视觉设计与设计文档，不直接修改 `Code文档` 下的业务代码。
- 页面重设计必须遵守已确认 Spec、里程碑、产品边界和当前业务术语。
- 设计稿不得暗示平台已具备未实现能力，例如实名认证、担保交易、人工仲裁、自动推荐、客服实时处理等。
- 每次输出大方向改版、小细节调整、阶段定稿或设计交接后，必须追加 `UI设计师工作记录.md`。
- 涉及用户联系方式、未成年人、审核、投诉、支付或身份认证的 UI 表达，必须先确认产品口径。
