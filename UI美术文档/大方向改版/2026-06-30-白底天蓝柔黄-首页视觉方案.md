# 白底天蓝柔黄首页视觉方案

## Overview

这版视觉把白色作为最大面积的基底，整体页面不再依赖厚重色块或明显阴影，而是用干净白卡、细边框和充足留白建立可信感。天蓝色作为主行动色和流程识别色，明度偏高、饱和度适中，读起来像晴天和校园感，不会像企业蓝那样压迫。柔黄只作为极少量状态或标签点缀，不在首屏大量出现。

首页应该像一个清爽的本地教育服务入口，而不是培训机构广告页。第一屏保留当前项目的真实内容：东莞大学城家教对接、找家教、做家教、个人页面，以及四步核心闭环。设计目标是让家长觉得可信、学生老师觉得门槛低，同时让平台的 MVP 边界表达得诚实。

**Key Characteristics:**

- 白色优先：`{colors.surface-card}` 承载绝大多数卡片和按钮，`{colors.canvas}` 只给页面一点冷白蓝底色。
- 舒缓天蓝：`{colors.primary-sky}` 用于主 CTA、步骤编号和少量导航强调，不大面积铺满。
- 柔黄点睛：`{colors.accent-yellow}` 不做主按钮，只保留在小型状态标签或后续提示中，避免视觉发散。
- 低阴影、细边框：卡片主要依靠 `{colors.hairline}` 分隔，不使用厚重投影。
- 简洁但不呆板：主要通过蓝色流程块、留白和清晰卡片节奏制造活泼感。

## Colors

### Brand & Accent

- **Sky Blue** (`{colors.primary-sky}` - `#62B8E8`)：主行动色。用于“我要找家教”、流程编号、关键链接和选中状态。它应该舒缓、明亮、可信，不应变成深蓝政务感。
- **Soft Yellow** (`{colors.accent-yellow}` - `#F6C84F`)：辅助强调色。只用于少量轻标签或温暖提醒。不能和蓝色抢主次，也不能铺成大面积背景。

### Surface

- **Canvas** (`{colors.canvas}` - `#F7FBFE`)：页面底色，是接近白色的微蓝背景，用来降低纯白刺眼感。
- **Surface Card** (`{colors.surface-card}` - `#FFFFFF`)：卡片、导航、表单、列表和主要信息区。白色使用范围最大。
- **Sky Soft** (`{colors.primary-sky-soft}` - `#E8F6FD`)：流程步骤、空状态、提示模块的轻背景。
- **Yellow Soft** (`{colors.accent-yellow-soft}` - `#FFF4CF`)：轻强调背景，例如“本地小范围试运行”“双向同意后交换联系方式”。

### Hairlines

- **Hairline** (`{colors.hairline}` - `#DDEAF2`)：卡片边框、导航底线、分隔线。用来替代厚阴影。

### Text

- **Ink** (`{colors.ink}` - `#182333`)：标题、重要信息、按钮外的主要文字。
- **Body** (`{colors.body}` - `#425466`)：正文说明。
- **Muted** (`{colors.muted}` - `#6B7A8C`)：辅助说明、时间、状态和次级信息。

## Typography

首页标题使用较大字号和中高字重，但不使用过粗黑体。中文标题要清楚、稳，不要像招生海报。正文保持 16-18px 的舒适阅读尺寸，行高偏松，降低家长第一次阅读规则和流程时的心理负担。

### Principles

- 标题靠字号和留白建立层级，不靠极粗字重。
- 按钮文字短促明确，例如“我要找家教”“我要做家教”。
- 不使用负字距。
- 移动端标题自动降级，避免首屏被大字吃满。

## Layout

首页保留当前的两栏首屏结构：左侧是品牌和行动入口，右侧是平台流程。新的布局让右侧流程卡更像“安心闭环说明”，而不是技术步骤。首屏下方的 MVP 入口继续使用三张卡片，但卡片不再增加角标圆点或额外装饰，只保留英文小标签和清晰文字层级。

### Spacing Philosophy

大区块使用 `{spacing.section}` 保持呼吸感；卡片内部使用 `{spacing.lg}` 和 `{spacing.base}`，避免拥挤。按钮组保留 12-14px 间距，移动端纵向排列。

## Elevation

默认不使用明显阴影。首页卡片可以使用非常轻的蓝色环境阴影，但不得成为视觉主角。主要层级来自白底、微蓝页面底、细边框和色块分区。

## Components

**`button-primary`**：主 CTA。背景为 `{colors.primary-sky}`，文字为 `{colors.on-primary}`。只用于最关键的行动，例如“我要找家教”。禁用状态降低透明度，不改成黄色。

**`button-secondary`**：次级行动。白底、蓝色文字、细边框，用于“我要做家教”“个人页面”。hover 可使用 `{colors.primary-sky-soft}`。

**`card`**：默认内容卡片。白底、细边框、12px 圆角、轻微环境阴影或无阴影。用于 MVP 入口、流程面板和提示模块。

**`flow-step`**：流程步骤。浅蓝底、白卡内嵌、左侧蓝色编号。四步流程仍是发布信息、筛选详情、站内沟通、双向同意。

**`highlight-pill`**：柔黄标签。仅在确有必要时用于“本地小范围试运行”“MVP”等轻强调，不作为按钮，也不成组堆叠。

## Page Structure

1. 顶部导航：白底半透明或纯白，底部使用细边框；品牌文字使用蓝色深一阶。
2. 首屏左侧：大标题 + 说明文案 + 三个行动按钮，不放多枚胶囊标签。
3. 首屏右侧：白色流程卡，内部四个浅蓝步骤，不额外给单个步骤加黄色底。
4. MVP 入口：三张白色卡片，分别对应需求广场、家教信息广场、风险与功能反馈；卡片不使用装饰圆点。
5. 风险边界：反馈卡或轻提示中可说明“先记录反馈，不承诺即时人工仲裁”。

## Business Boundary

这版 UI 不得暗示：

- 平台已完成实名认证或资质审核。
- 平台提供担保交易、在线支付、退款或合同。
- 平台提供即时人工客服、人工仲裁或纠纷处理。
- 平台保证教学质量或老师身份真实性。
- 平台已有自动推荐算法、复杂排课、课时记录或评价体系。

## Responsive Behavior

| Name | Width | Key Changes |
| --- | --- | --- |
| Mobile | < 720px | 首页首屏改为单列；按钮纵向排列；流程卡在标题之后；MVP 卡片单列。 |
| Tablet | 720-1024px | 首屏可继续单列或弱双列；MVP 卡片 2 列后换行。 |
| Desktop | 1024-1440px | 首页使用左右双列；MVP 卡片 3 列；内容最大宽度控制在 1120-1180px。 |
| Wide | > 1440px | 页面居中，内容不无限拉伸，外侧留白吸收宽屏空间。 |

### Touch Targets

- 主 CTA 不小于 44 x 44px。
- 表单输入框后续统一不小于 44px，移动端建议 48px。

### Collapsing Strategy

- 导航在移动端可压缩为换行或菜单。
- 卡片从 3 列降到 1 列。
- 流程步骤保持纵向，不使用横向时间轴。

## Known Gaps

- 本稿只覆盖首页大方向预览，不代表列表页、表单页、聊天页已经定稿。
- 动效、插画、图标系统尚未定义。
- 深色模式不在本次范围。
- 本设计文档不是产品验收结论，也不代表相关功能已经实现。
