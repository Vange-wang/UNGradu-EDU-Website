# 整站重排版：简单但不低调

## Overview

这次不沿用旧的“所有页面都放进一个白色面板”的结构。整站改成更明确的产品型界面：页面仍然干净，但布局更大胆，视觉更有记忆点。白色依然是最大面积基底，天蓝承担按钮、导航焦点、筛选区和流程结构，黄色只在关键状态和强调短语中出现。

“简单但不低调”的核心不是增加装饰，而是让每个页面都有自己的版式重心。首页要像入口海报，广场要像筛选工作台，发布页要像分步填写面板，聊天页要像消息工具，个人页要像控制台。这样用户一看就知道自己在哪，而不是每页都像一张普通文档卡。

**Key Characteristics:**

- 强版式：打破旧的居中面板，把页面重心改成左右分区、分步区、工作台区。
- 强行动：主按钮更清楚，首屏和列表页的行动入口更靠前。
- 少装饰：不用到处贴圆点和标签，视觉存在感来自大标题、色块区、卡片秩序。
- 业务诚实：不通过 UI 暗示认证、担保、人工客服或交易能力。

## Page System

### 1. 首页：Gateway Layout

首页从“左文案 + 右流程卡”升级为“大标题入口 + 角色选择 + 流程横向模块”。第一屏不再像说明页，而像平台入口。家长和老师两条路径并列，用户先选择身份，再进入发布或浏览。

关键结构：

- 顶部导航保持白底，但品牌区加天蓝识别。
- 首屏使用大标题和一块大面积浅蓝行动区。
- 两个身份入口卡片并列：找家教、做家教。
- 四步流程放在首屏下缘或第二屏顶部，减少右侧卡片的说明感。

### 2. 广场页：Filter Workbench

需求广场和家教信息广场使用同一工作台结构：左侧固定筛选栏，右侧是结果列表。旧版横向筛选条字段太挤，改成左侧筛选更像真正的查找工具。

关键结构：

- 页面顶部是标题、说明、发布按钮。
- 左侧浅蓝筛选面板，字段纵向排列。
- 右侧结果卡片使用两列或一列列表，重点信息先展示：科目 / 学段 / 价格 / 区域。
- 空状态不只显示一句话，给出“发布入口”或“清空筛选”行动。

### 3. 发布页：Step Form

家长发布需求和老师发布家教信息不再是长表单堆叠，改成分步卡片：基础信息、教学信息、时间与价格、补充说明。页面左侧显示进度说明，右侧填写内容。

关键结构：

- 顶部说明当前表单不会公开联系方式。
- 表单分组使用编号和短标题。
- checkbox 变成清晰的选项块。
- 底部固定或明显放置主提交按钮。

### 4. 聊天页：Conversation Workspace

聊天页改成三栏或强两栏：左侧会话上下文，中间消息区，右侧联系方式交换状态。当前联系方式交换是核心安全能力，不能只是旁边一块普通卡片。

关键结构：

- 中间消息区独立、留足高度。
- 右侧交换状态分为“未授权 / 待处理 / 已授权”。
- 请求交换联系方式按钮只在右侧状态区出现。
- 输入框更像消息工具，不像普通表单。

### 5. 个人页：Account Dashboard

个人页从链接列表改成仪表盘：账号状态、联系方式、我的发布、我的聊天、密码设置分区。用户进入后能立即知道自己能做什么。

关键结构：

- 顶部账号摘要卡。
- 四个主要功能入口用 2x2 控制台卡片。
- 密码设置和退出登录放到底部安全区。

### 6. 登录 / 规则 / 反馈：Utility Pages

登录页使用双栏：左侧说明登录方式和安全边界，右侧登录表单。规则和反馈页使用公告式布局，左侧大标题，右侧重点条目，不再只是单段文字。

## Colors

### Brand & Accent

- **Sky** (`{colors.sky}`)：主按钮、导航高亮、筛选面板、步骤编号。
- **Sky Deep** (`{colors.sky-deep}`)：品牌文字、链接、重要标题的小强调。
- **Yellow** (`{colors.yellow}`)：只用于强调“免费 MVP”“联系方式保护”“本地试运行”等短标签。

### Surface

- **Canvas** (`{colors.canvas}`)：页面底色，保持白净但不刺眼。
- **Surface** (`{colors.surface}`)：卡片和表单。
- **Navy Panel** (`{colors.navy-panel}`)：仅用于少量强对比模块，例如首页底部流程带或规则强调区，不大面积铺开。

## Components

**`command-button`**：高识别主按钮。用于发布、筛选、发送、提交。全站主行动统一天蓝。

**`quiet-button`**：次级按钮。用于返回、重置、查看详情。

**`data-card`**：广场结果卡、个人中心入口、规则条目。白底、细边框、清晰标题。

**`side-filter`**：广场页左侧筛选面板。浅蓝底、纵向字段，让筛选成为页面结构的一部分。

## Responsive Behavior

| Name | Width | Key Changes |
| --- | --- | --- |
| Mobile | < 720px | 所有工作台降为单列；筛选面板置顶；按钮全宽；聊天侧栏下移。 |
| Tablet | 720-1024px | 广场可保持筛选置顶 + 两列结果；个人中心 2 列卡片。 |
| Desktop | 1024-1440px | 使用左右工作台、双栏表单、三列入口卡。 |
| Wide | > 1440px | 内容最大宽度 1180-1240px，避免无限拉伸。 |

## Business Boundary

全站 UI 不得暗示：

- 平台已完成实名认证或资质审核。
- 平台提供担保交易、在线支付、退款或合同。
- 平台提供即时人工客服、人工仲裁或纠纷处理。
- 平台保证教学质量或老师身份真实性。
- 平台已有自动推荐算法、复杂排课、课时记录或评价体系。
