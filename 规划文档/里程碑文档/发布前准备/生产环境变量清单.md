# 生产环境变量清单

日期：2026-06-24
阶段：MVP 发布前准备

## 1. 正式生产必填变量

| 变量名 | 用途 | 是否必填 | 配置位置 | 要求 |
| --- | --- | --- | --- | --- |
| `APP_ENV` | 应用运行环境主闸 | 是 | CloudBase Run 环境变量 | 正式生产必须为 `production` |
| `AUTH_SESSION_SECRET` | 签名 HttpOnly 会话 Cookie | 是 | CloudBase Run 私密环境变量 | 生产专用强随机密钥，不得复用测试密钥 |
| `CLOUDBASE_ENV_ID` | CloudBase 环境 ID | 是 | CloudBase Run 环境变量 | 使用生产或正式试运行 CloudBase 环境 |
| `TENCENTCLOUD_SECRETID` | 腾讯云访问 SecretId | 是 | CloudBase Run 私密环境变量 | 只在控制台配置，不写入 Git 或文档正文 |
| `TENCENTCLOUD_SECRETKEY` | 腾讯云访问 SecretKey | 是 | CloudBase Run 私密环境变量 | 只在控制台配置，不写入 Git 或文档正文 |

## 2. 正式生产禁止变量

| 变量名 | 生产要求 |
| --- | --- |
| `M5_ENABLE_HOSTED_TEST_LOGIN` | 不设置，且不得配置为 `true` |
| `NEXT_PUBLIC_ALLOW_TEST_LOGIN` | 不设置，且不得配置为 `true` |

`APP_ENV=production` 是禁用测试登录的主闸。即使误将 `M5_ENABLE_HOSTED_TEST_LOGIN=true` 或 `NEXT_PUBLIC_ALLOW_TEST_LOGIN=true` 配入生产环境，服务端仍必须拒绝 `/api/auth/test-login` 和 `x-ungradu-test-user-phone` 备用测试身份。

## 3. 密钥生成与轮换

- `AUTH_SESSION_SECRET` 必须使用生产专用强随机值。
- 真实 `AUTH_SESSION_SECRET`、`TENCENTCLOUD_SECRETID`、`TENCENTCLOUD_SECRETKEY` 不得写入 Git、规划文档正文或聊天记录归档。
- 若疑似泄露，应立即在 CloudBase 控制台轮换密钥并重新部署。
- 轮换 `AUTH_SESSION_SECRET` 会使现有签名会话失效，可能导致全部在线用户被强制登出；轮换前需确认窗口并通知业务方。

## 4. 生产登录阻塞说明

若生产仍未接入正式短信登录或业务确认的登录方案，则不能把 M5 测试登录当作真实用户登录方式。此状态下可继续做生产发布演练和内部试运行准备，但不得面向真实公网用户宣称正式生产可用。
