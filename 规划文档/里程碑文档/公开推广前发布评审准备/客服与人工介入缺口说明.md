# 客服与人工介入缺口说明

日期：2026-06-30

阶段：发布阶段 S4

## 1. 当前状态

当前平台没有正式客服系统、人工介入工作台、客服值守机制或投诉处理 SLA。

当前反馈入口只能用于记录和后续排查问题，不代表平台能够即时处理纠纷、人工仲裁、退款、封禁或资质争议。

## 2. 对公开推广的影响

在该能力未建设前：

- 不建议公开推广到陌生大流量用户。
- 不建议宣传“客服可处理纠纷”。
- 不建议承诺“平台人工审核”。
- 不建议承诺“平台担保交易”。
- 不建议承接高风险线下交易纠纷。

## 3. 小范围试运行可用口径

可以表述为：

- 当前为 MVP 小范围试运行。
- 平台提供发布、浏览、聊天、联系方式交换等基础撮合能力。
- 平台当前不提供即时客服、人工介入、担保交易或退款仲裁。
- 如发现风险或功能异常，可通过反馈入口提交，平台将用于后续排查和迭代。

## 4. 后续补齐方向

- 智能 Agent 客服专项。
- 举报 / 投诉处理流程。
- 人工审核与处理工作台。
- 风险事件记录与追踪。
- 客服处理边界和响应 SLA。
- 数据权限与隐私审计。
