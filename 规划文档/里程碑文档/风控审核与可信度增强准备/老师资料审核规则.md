# 老师资料审核规则

日期：2026-06-30

阶段：发布阶段 S3

## 1. 当前口径

当前 MVP 不承诺平台已完成老师身份认证、学校认证、资质认证或背景审核。

老师资料在当前阶段只能表达为“用户自行填写的信息”，不得暗示“平台认证老师”“官方认证资质”“已人工审核通过”。

## 2. 老师资料建议字段风险

| 字段 | 风险 | S3 规则 |
| --- | --- | --- |
| 姓名 / 昵称 | 真实身份不可确认 | 可展示昵称或称呼，不作为认证依据 |
| 学校 / 专业 | 可能虚假 | 仅作为用户自填信息展示 |
| 可教科目 | 可能夸大 | 仅作为意向能力，不构成平台保证 |
| 课时费 | 可能引发价格纠纷 | 明确由双方沟通确认，平台不做担保 |
| 证明图片 | 可能含隐私或伪造 | 当前不建立认证等级；后续需单独审核规则 |
| 联系方式 | 隐私泄露 | 不在公开资料直接展示，通过交换机制展示 |

## 3. 当前允许展示

- 昵称 / 称呼。
- 学校 / 专业等自填介绍。
- 可教科目、学段、课时费范围。
- 教学经验、可上课方式等自填描述。

## 4. 当前不应展示或不应承诺

- 不展示完整联系方式。
- 不展示身份证、学生证等敏感证件原图。
- 不写“平台认证”。
- 不写“已核验真实身份”。
- 不写“保证教学质量”。

## 5. 后续审核能力建议

后续若建设审核能力，应单独规划：

- 资料提交标准。
- 证明材料脱敏要求。
- 审核状态：待审核、通过、驳回、需补充。
- 审核操作记录。
- 审核责任边界。
- 申诉和撤回机制。
