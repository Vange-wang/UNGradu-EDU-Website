## 问题描述

业务方在当前生产环境的真实 Chrome 浏览器中发现，同一全站 UI 刷新任务仍存在以下三类关联回归：

1. Chrome 100% 缩放时，除智能客服页外，首页及其他设计页的整体尺寸和构图明显过大或发生溢出；切换至 90% 缩放后才更接近预期，说明默认 100% 缩放适配不合格。

3. 首页主标题“大学生家教平台”的字体、描边和阴影厚度未按业务方最终确认的图三样式呈现。
