## 2. 部署前核对

- `APP_ENV=production`。
- `AUTH_SESSION_SECRET` 已配置，且为生产独立强随机值。
- `CLOUDBASE_ENV_ID` 指向生产环境，不指向测试环境。
- `EMAIL_CODE_SECRET` 已配置，且为生产独立强随机值。
- `EMAIL_PROVIDER=smtp`。
- SMTP 配置完整：`SMTP_HOST`、`SMTP_PORT`、`SMTP_SECURE`、`SMTP_USER`、`SMTP_PASS`、`EMAIL_FROM`。
- 腾讯云密钥完整：`TENCENTCLOUD_SECRETID`、`TENCENTCLOUD_SECRETKEY`。
- 生产环境未启用 `M5_ENABLE_HOSTED_TEST_LOGIN=true`。
- 生产环境未启用 `NEXT_PUBLIC_ALLOW_TEST_LOGIN=true`。

## 3. 部署后核对

- 首页可访问。
- `/login` 不显示测试登录入口。
- `/api/auth/test-login` 在生产环境拒绝测试登录。
- 未登录导航显示“登录 / 注册”。
- 验证码发送可用。
- 验证码登录可用。
- 密码登录可用。
- 发布需求 / 发布家教信息可用。
- 聊天和联系方式交换可用。
- 退出登录后导航 UI 同步。

## 4. 回滚条件

出现以下任一情况，应考虑回滚或暂停发布：

- P0 问题无法在短时间内修复。
- 生产测试登录被打开。
- 登录态或权限判断失效。
- 联系方式或内部字段泄露。
- 生产数据库集合缺失导致主链路不可用。
