# 联系方式与隐私保护规则

日期：2026-06-30

阶段：发布阶段 S3

## 1. 基本原则

- 联系方式默认不公开。
- 只有双方通过联系方式交换流程后，才展示授权联系方式。
- 未成年人相关信息应最小化展示。
- 平台不得在公开页面展示密码、验证码、密码 hash、验证码 hash、ownerUserId、集合名或内部请求 ID。

## 2. 联系方式展示规则

| 场景 | 是否展示联系方式 | 规则 |
| --- | --- | --- |
| 首页 / 广场列表 | 否 | 只展示业务摘要 |
| 需求详情 / 家教详情 | 否 | 可发起聊天或交换请求 |
| 聊天未同意交换 | 否 | 不展示对方联系方式 |
| 双方同意并二次确认 | 是 | 只展示双方已填写的联系方式 |
| 交换撤回 / 拒绝 / 过期 | 否 | 不展示联系方式 |

## 3. 隐私提醒

应在后续页面优化中优先补充：

- 不要在公开需求或家教介绍中填写电话、微信、家庭住址、身份证号。
- 未成年人相关信息只写必要学习需求，不写完整住址、学校班级、身份证等敏感信息。
- 线下见面、付款、试课需自行谨慎判断。
- 平台当前不提供担保交易和退款仲裁。

## 4. 数据最小化

- 公开 View Model 只返回展示所需字段。
- 私有 owner 字段只用于服务端权限判断。
- 密码 hash、salt、验证码 hash、验证码状态不得返回前端。
- 日志和错误提示不得包含完整密钥、验证码、密码或联系方式。

## 5. 当前不做

- 不做自动敏感信息识别。
- 不做聊天内容实时审查。
- 不做人工隐私审核。
- 不做智能 Agent 隐私识别。
