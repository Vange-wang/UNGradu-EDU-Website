# UI设计师工作记录

用途：持续记录 UI 设计师在本项目中的每次重要操作、设计输入、设计决策、目录调整、设计稿输出、阶段定稿和交接动作。后续 UI 设计师会话应持续追加更新本文件。

## 记录规则

- 新增或变更 UI 设计方向时，必须追加记录。
- 新增草图模板、大方向改版、小细节调整、阶段设计定稿或设计交接文档时，必须追加记录。
- 更新 `钦定UI设计师.md`、`UI设计师Agent身份注册信息.md` 或 `UI美术文档/README.md` 时，必须追加记录。
- 记录应包含日期、类型、涉及文档、内容摘要和影响。
- 不记录业务代码实现细节，除非该实现结果反向影响 UI 设计交接。
- 不把未被用户确认的视觉方案写成“已定稿”。
