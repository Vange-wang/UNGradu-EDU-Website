# 智能 Agent 客服后期专项规划入口

日期：2026-06-30

阶段：发布阶段 S4

## 1. 专项定位

智能 Agent 客服不是 S4 当前交付物，而是后期独立专项。

该专项可作为未来客服与人工介入能力不足时的辅助承接层，但不能在当前阶段替代真实人工责任边界。

## 2. 后期专项建议拆解

### A. 咨询问答 Agent

- 回答平台规则。
- 引导用户如何发布需求 / 家教信息。
- 解释联系方式交换流程。
- 提醒隐私和线下交易风险。

### B. 风险反馈分流 Agent

- 根据用户反馈初步分级。
- 判断是否疑似骚扰、虚假信息、隐私泄露、功能故障。
- 生成内部处理记录。

### C. 人工升级接口

- 当涉及未成年人、联系方式泄露、纠纷、退款、资质争议时，必须升级。
- 若没有人工承接，则 Agent 必须明确“当前无法即时处理”。

## 3. 必须先定义的边界

- Agent 可以读取哪些数据。
- Agent 不可以读取哪些数据。
- Agent 是否能查看聊天内容。
- Agent 是否能查看联系方式交换记录。
- Agent 是否能主动联系用户。
- Agent 误答由谁负责。
- Agent 处理结果如何追溯。

## 4. 当前 S4 结论

智能 Agent 客服未建设，因此当前不作为公开推广已具备条件。
