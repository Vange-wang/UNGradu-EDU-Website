## 描述

项目总控制人在正式环境试用中反馈：发布家教信息时，课时费/学段当前只能填写一组。实际业务中老师可能对不同学段设置不同课时费，需要支持多组“学段 + 课时费”，并提供加号小交互按钮新增条目。

## 严重级别

P1。

## 责任归因

体验/功能缺口。当前表单能力不能完整表达老师面向多学段的收费结构。

## 修复动作

- 产品经理补充多组“学段 + 课时费”的验收口径，包括最少/最多条目、必填规则、删除规则和展示规则。
- 代码开发员实现多组输入、保存、校验和展示。
- 回归验证老师资料发布与展示流程。

## 关闭条件

产品经理确认验收口径，代码开发员完成实现并提交，正式环境或可复验环境中确认可新增、保存和展示多组“学段 + 课时费”。

## 处理记录

- 2026-06-28：由 ISSUE 管理员 Agent 根据正式环境试用反馈登记为 Open。
- 2026-06-28：根据《登录与发布体验优化第一次最终审查报告》，产品经理与 ZCode 结论一致，代码开发员无需返工；本 Issue 从 Open 更新为 Closed，并归档至 `Close_Issue`。
