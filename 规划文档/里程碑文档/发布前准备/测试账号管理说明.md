# 测试账号管理说明

日期：2026-06-24
阶段：MVP 发布前准备

## 1. 账号分类

| 类型 | 使用范围 | 说明 |
| --- | --- | --- |
| 本地测试账号 | 本地开发 | 仅用于开发和自动化测试 |
| M5 托管测试账号 | `APP_ENV=test` 且隔离托管服务 | 仅用于 `npm run m5:hosted:verify` 等验收脚本 |
| 试运行账号 | 正式试运行环境 | 必须与测试账号和真实用户账号区分 |
| 真实用户账号 | 正式生产 | 不得使用 M5 测试登录创建 |

## 2. 测试登录边界

- 测试账号只能用于 `APP_ENV=test` 或本地开发环境。
- 生产环境不得开放 `/api/auth/test-login` 作为普通用户登录方式。
- 生产环境不得接受通过 `x-ungradu-test-user-phone` 请求头传入的备用测试身份。
- `APP_ENV=production` 时，`readAuthenticatedUserId` 经 `isTestLoginAllowed` 闸门必须拒绝测试身份。

## 3. 测试数据识别与清理

M5 脚本生成的需求、家教信息、会话、消息和联系方式交换记录应通过以下方式之一识别：

- 使用脚本内固定测试手机号段。
- 使用创建时间范围。
- 使用测试内容前缀或脚本生成标记。
- 在隔离测试 CloudBase 环境中运行，避免与生产数据混放。

测试数据清理必须限定环境、账号前缀或时间范围，不得在生产集合中执行无筛选批量删除。

## 4. 测试托管环境与生产隔离

当前 M5 测试托管服务为 `ungradu-edu-m5-test`。该服务只能用于 M5 验收和后续内部复验，不等同于正式生产服务。

若继续保留测试托管环境，应确保：

- 使用独立 `APP_ENV=test`。
- 仅测试托管环境可配置 `M5_ENABLE_HOSTED_TEST_LOGIN=true`。
- 测试环境使用独立 CloudBase 数据与密钥。
- 测试数据清理策略不触达正式生产数据。
