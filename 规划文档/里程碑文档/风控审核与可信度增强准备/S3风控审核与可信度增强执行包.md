# S3 风控审核与可信度增强执行包

日期：2026-06-30

任务 ID：`RELEASE-S3-TRUST-2026-06-30-001`

阶段：发布阶段 S3

阶段名称：风控、审核与可信度增强

前置状态：S1 已完成；S2 生产运行观察与运维基线已通过；当前 Open Issue 为空。

## 1. 背景

当前 MVP 已能完成家长 / 学生发布需求、老师发布家教信息、站内聊天、联系方式交换、邮箱验证码登录、密码登录等核心链路。

S3 的目标不是继续扩大功能，而是为当前小范围生产试运行建立可信边界：

- 老师资料哪些内容需要审核。
- 联系方式展示与交换如何降低隐私风险。
- 未成年人相关信息如何保护。
- 用户如何发现风险提示、举报入口和信息撤回边界。
- 当前没有客服 / 人工介入能力时，平台如何描述能力边界。

## 2. S3 目标

- 明确老师资料审核边界。
- 明确联系方式展示、交换和风险提示规则。
- 明确未成年人相关隐私保护规则。
- 明确举报入口、风险提示、信息撤回和基础处置边界。
- 明确客服与人工介入能力缺口，并将智能 Agent 客服列为后期专项。

## 4. S3 不做范围

- 不实现客服与人工介入。
- 不实现智能 Agent 客服。
- 不建设复杂审核后台。
- 不接入实名认证供应商。
- 不建立资质认证等级体系。
- 不做自动风控模型。
- 不做支付、退款、合同、排课、评价。
- 不扩大公开推广。

## 5. 当前能力边界

当前可依赖能力：

- 登录态。
- 发布需求 / 发布家教信息。
- 站内聊天。
- 联系方式交换。
- 反馈入口。
- 生产运行观察与 Issue 登记流程。

当前不可承诺能力：

- 平台人工审核值守。
- 平台人工客服。
- 平台即时介入纠纷。
- 平台认证老师身份真实性。
- 平台担保交易或退款处理。
