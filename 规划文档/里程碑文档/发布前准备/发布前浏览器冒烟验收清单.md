## 2. 环境要求

- 本地或 M5 测试托管环境可使用受控测试登录。
- 若使用正式生产环境验证，必须确认测试登录已禁用，不能使用 M5 测试登录路径。
- 冒烟记录不得包含真实手机号、真实微信号或真实密钥。

## 3. 当前状态

本轮执行环境：本地 Next dev 服务 `http://127.0.0.1:3000`，Chrome headless DOM 冒烟 + 本地真实 HTTP API flow/load。

执行结果：

- `npm run m5:http:flow`：通过，1 对用户 / 2 虚拟用户，15 个请求，成功率 100.00%，错误率 0.00%。
