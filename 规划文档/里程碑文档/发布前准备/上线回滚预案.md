# 上线回滚预案

日期：2026-06-24
阶段：MVP 发布前准备

## 1. 当前版本基线

- 当前开发分支：`codex/m5-security-preflight`
- M5 托管测试服务：`ungradu-edu-m5-test`
- M5 托管测试地址：`https://ungradu-edu-m5-test-273732-8-1445807473.sh.run.tcloudbase.com`
- M5 托管最终验收：`npm run m5:hosted:verify` 已在真实公网托管地址下通过。

正式生产发布前，应记录当次准备上线的 Git 提交 SHA、CloudBase Run 镜像版本和环境变量配置快照。

## 2. 回滚触发条件

- 首页或核心页面不可访问。
- 登录入口行为与环境配置不一致。
- 发布、筛选、详情、聊天或联系方式交换核心路径异常。
- `APP_ENV=production` 下测试登录可用。
- CloudBase Run 新版本启动失败或持续返回非预期错误页。

## 3. 回滚步骤

1. 暂停继续发布，通知业务方和测试人员当前进入回滚窗口。
2. 在 CloudBase Run 控制台选择上一稳定镜像或上一稳定部署版本。
3. 恢复上一稳定环境变量配置，尤其是 `APP_ENV`、`AUTH_SESSION_SECRET`、`CLOUDBASE_ENV_ID` 和腾讯云密钥配置。
4. 如本次发布包含代码提交回退，在 Git 中确认上一稳定提交并重新构建镜像。
5. 部署回退版本后执行回滚验证。
6. 记录故障现象、回滚版本、验证结果和后续修复负责人。

## 4. 回滚后最低验证

- 首页可访问。
- 登录入口行为符合当前环境配置。
- `APP_ENV=production` 下 `/api/auth/test-login` 不可用。
- 通过 `x-ungradu-test-user-phone` 请求头传入测试身份时，生产环境拒绝。
- 发布、筛选、详情、聊天、联系方式交换核心路径至少完成一轮冒烟检查。

## 5. 沟通要求

回滚期间需同步业务方和测试人员：

- 当前影响范围。
- 预计恢复时间。
- 已回退到的版本或镜像。
- 回滚后仍需补充验证的路径。

本预案不包含任何真实密钥。真实环境变量只允许在 CloudBase 控制台或经授权的密钥管理位置查看和修改。
