# 生产问题分级与响应规则

日期：2026-06-30

适用阶段：发布阶段 S2 生产运行观察与运维基线

## 1. 分级规则

| 等级 | 判定标准 | 处理方式 |
| --- | --- | --- |
| P0 | 主链路整体不可用；隐私数据泄露；越权读取 / 写入；真实密钥泄露；测试登录在生产可用 | 立即暂停扩大试运行，登记 Issue，优先修复或回滚 |
| P1 | 登录、验证码、密码、发布、聊天、联系方式交换等核心链路局部失败；生产环境变量配置错误；数据库集合缺失 | 当日定位，登记 Issue，进入修复或外部依赖处理 |
| P2 | 返回入口、提示文案、单页体验、非核心展示问题影响使用但不阻断主链路 | 记录观察，必要时登记 Issue，排入下一轮体验修复 |
| P3 | 文档、样式、运营说明、内部记录不完整 | 进入产品迭代或文档修订，不阻塞 S2 |

## 2. 响应流程

1. 记录发现时间、发现人、环境、页面、账号类型和复现步骤。
2. 按 P0-P3 初判等级。
3. P0 / P1 必须登记 Issue；P2 由总负责人判断是否登记；P3 可进入迭代池。
4. 涉及代码修复时，必须基于当前生产发布基线新建或延续语义化分支。
5. 修复后必须记录目标 commit、验证命令、生产复验结论。
6. 不得复用 S1 已关闭 Issue；S2 新问题从 `ISSUE-0016` 起继续编号。

## 3. 暂停扩大试运行条件

出现以下任一情况，应暂停扩大试运行：

- 生产测试登录可被普通用户使用。
- 普通用户可看到他人联系方式、内部 ID、集合名或服务端错误堆栈。
- 验证码、密码登录或会话能力整体不可用。
- 发布需求 / 家教信息无法保存。
- 聊天或联系方式交换出现越权。
- 真实密钥、验证码明文、密码明文出现在日志、页面或仓库。

## 4. 非阻塞事项

以下事项不阻塞 S2 完成，但必须进入记录：

- 客服与人工介入能力缺失。
- 智能 Agent 客服尚未建设。
- 支付、排课、评价、实名认证、资质认证尚未建设。
- 大规模公开推广前的运营承接能力尚未完成。
