# 举报入口与风险提示最小闭环说明

日期：2026-06-30

阶段：发布阶段 S3

## 1. 当前可用入口

当前平台已有反馈入口，可作为临时风险反馈入口使用。

在没有客服与人工介入能力前，该入口只能承接“记录和后续排查”，不能承诺即时处理、人工仲裁或客服响应。

## 2. 最小闭环

| 步骤 | 当前 S3 规则 |
| --- | --- |
| 用户发现风险 | 通过反馈入口提交问题 |
| 平台记录 | 由总负责人或后续运营角色记录到工作记录 / Issue |
| 问题分级 | 按 S2 P0-P3 规则判断 |
| 技术问题 | 登记 Issue，进入修复流程 |
| 产品 / 规则问题 | 进入产品迭代或后续 S3/S4 规划 |
| 需要客服 / 人工介入 | 标记为能力缺口，不承诺当前可处理 |

## 3. 建议风险提示位置

后续若进入代码任务，建议补充：

- 发布需求表单。
- 发布家教信息表单。
- 需求详情页。
- 家教信息详情页。
- 聊天页联系方式交换确认区域。
- 反馈页。

## 4. 风险提示建议文案口径

可用口径：

- 请勿在公开内容中填写电话、微信、家庭住址、身份证号等敏感信息。
- 联系方式请通过平台交换流程确认。
- 平台当前不提供支付担保、退款仲裁或即时客服介入。
- 如发现虚假信息、骚扰或隐私风险，请通过反馈入口提交。

避免口径：

- “平台已审核所有老师”。
- “平台保证老师真实可靠”。
- “平台可即时处理纠纷”。
- “平台担保交易安全”。

## 5. 当前不做

- 不做客服工单系统。
- 不做人工介入工作台。
- 不做自动封禁。
- 不做举报处理 SLA 承诺。
